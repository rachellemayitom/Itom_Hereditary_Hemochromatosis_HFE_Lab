### Disease and Gene

- **Disease/Phenotype:** Hereditary hemochromatosis
- **Gene:** HFE
- **Official gene name:** Homeostatic iron regulator
- **Chromosome:** 6p22.2

### Reference Sequences

- **Reference transcript:** NM_000410.4
- **Reference protein:** NP_000401.1
- **Sequence type:** Coding Sequence (CDS)
- **CDS location:** 13–1059
- **Database:** NCBI RefSeq
- **WT CDS length:** 1,047 bp
- **WT protein length:** 348 aa

### Documented Disease-Associated Variant

- **Variant:** NM_000410.4(HFE):c.845G>A (p.Cys282Tyr)
- **Common name:** C282Y
- **Mutation type:** Missense single-nucleotide variant (SNV)
- **Nucleotide change:** G → A at c.845
- **Protein change:** Cys → Tyr at amino-acid position 282
- **ClinVar accession:** RCV000000019.77
- **Additional ClinVar record:** RCV000308358.32

The C282Y variant changes one amino acid while maintaining the reading frame and overall protein length. The analysis showed that the mutant protein remained 348 amino acids long and did not contain a premature stop codon.

### Artificial Mutation

An artificial one-nucleotide deletion was introduced at position c.4.

- **Deleted nucleotide:** G
- **WT CDS length:** 1,047 bp
- **Artificial mutant CDS length:** 1,046 bp
- **Mutation type:** 1-nucleotide deletion / frameshift
- **Effect:** Altered downstream amino acids and premature stop codons

The artificial mutation was created for computational comparison and does not represent the documented disease-causing HFE mutation.

### Analysis and Tools

The HFE reference and mutant sequences were analyzed using sequence-analysis tools, including:

- NCBI RefSeq
- Galaxy
- SeqKit
- MAFFT

The wild-type HFE protein was compared with the accepted reference protein, the documented C282Y mutant protein was compared with the wild type, and the artificial frameshift mutant was also translated and compared with the wild-type protein.
